Data Flow — a filtered request

User sets a filter

A selection in FilterBar.vue updates shared refs in the useFilters composable — selectedPeriod, selectedLocation, selectedCategory, selectedStatus (singleton state shared across all views).

View calls the API client

The active view (e.g. Dashboard.vue) calls getCurrentFilters() and passes the object to a method in api.js, such as api.getDashboardSummary(filters).

Axios builds the request

api.js turns the filter object into query params (skipping any set to 'all') and issues an HTTP GET to http://localhost:8001/api/….

FastAPI filters in memory

The matching route in main.py runs apply_filters() and filter_by_month() over the in-memory Python lists — no database query.

Pydantic validates the response

Results are shaped/validated against a response_model (e.g. List[InventoryItem]) and returned as JSON.

Vue renders via computed properties

The view stores raw data in refs and derives display values (totals, charts, formatted currency) through computed() properties — the DOM updates reactively.
